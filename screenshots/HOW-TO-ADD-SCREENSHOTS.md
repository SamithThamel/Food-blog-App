# How to Add Screenshots to README

## Required Screenshots

Please take screenshots of your application and save them in this folder with the following names:

1. **home-page.png** - Homepage showing recipe cards
2. **recipe-details.png** - Recipe details page with ingredients and instructions
3. **add-recipe.png** - Add recipe form page
4. **edit-recipe.png** - Edit recipe page with photo/video upload
5. **login-page.png** - Login/Register page
6. **about-page.png** - About page
7. **mobile-view.png** - Mobile responsive view (use browser dev tools)

## How to Take Screenshots

### For Desktop Views:

1. Open your application in the browser
2. Navigate to the desired page
3. Use one of these methods:
   - **Windows**: Press `Windows Key + Shift + S` or use Snipping Tool
   - **Mac**: Press `Cmd + Shift + 4`
   - **Browser**: Right-click → "Save as image" or use screenshot extensions

### For Mobile Views:

1. Open Chrome DevTools (F12)
2. Click the device toolbar icon (Ctrl+Shift+M)
3. Select a mobile device (iPhone, Samsung, etc.)
4. Take screenshot using browser's built-in tool:
   - Click the three dots menu in DevTools
   - Select "Capture screenshot"

## Tips for Better Screenshots

- ✅ Use full-page screenshots for better visibility
- ✅ Make sure the application is running with sample data
- ✅ Clear browser console to avoid clutter
- ✅ Use a consistent browser for all screenshots
- ✅ Resize images if they're too large (recommend max 1920px width)
- ✅ Use PNG format for better quality

## Screenshot Tools (Optional)

- **Windows**: Snipping Tool, Snip & Sketch, Greenshot
- **Mac**: Built-in Screenshot tool (Cmd+Shift+4)
- **Cross-platform**: Lightshot, ShareX, Flameshot
- **Browser Extensions**: Awesome Screenshot, Nimbus Screenshot

## After Adding Screenshots

Once you've added all screenshots to this folder, the README.md file will automatically display them.

## Alternative: Using Online Images

If you prefer, you can also:
1. Upload screenshots to an image hosting service (imgur, imgbb, etc.)
2. Update the README.md image paths with the hosted URLs

Example:
```markdown
![Home Page](https://i.imgur.com/your-image-id.png)
```
